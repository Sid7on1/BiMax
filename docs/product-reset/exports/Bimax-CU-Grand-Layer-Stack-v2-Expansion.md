## Confirmed against primary sources

- Electron documents `AXManualAccessibility`; PR #38102 fixed its old apparent-failure behavior.
- Apple documents desktop-independent window capture, one-shot screenshots, the Shortcuts CLI,
  Foundation Models updates, and FastVLM research/artifacts.
- VPI-Bench, WASP and CaMeLs support an untrusted-observation architecture and adversarial fixtures.
- CoAct-1 supports researching programmatic delegation, but Bimax must keep it inside the app-owned
  provider/broker rather than reopening engine shell tools in Control Mac turns.
- Agent Workflow Memory/OpenCUA support workflow/trajectory research; replay still needs fresh proof.
- WebDreamer, Agent JIT and Scaling Agents support later rehearsal/scheduling/judge experiments.
- MacArena contains 421 verified tasks across 50 apps and is an AIWILD workshop acceptance at ICML
  2026.

## Corrected errors and overclaims

- “BJudge October 2026” was wrong. arXiv:2510.02250 was submitted October 2025 and revised February
  2026.
- The searched Agent Workflow Memory primary page does not establish the draft's ICML-2025 label.
- MacArena is not described as an ICML main-track paper.
- A blog/third-party number is not “confirmed” by repetition. Capture/cache/token/latency numbers
  were removed from requirements and kept only as experiment leads.
- The Cua Driver repository documents private SkyLight/SPI mechanisms; it is competitive evidence,
  not an implementation source or stable public-platform contract.
- Regex injection scanning is advisory. Security requires typed data, trusted plan/authority, branch
  auditability and end-state adversarial tests.
- Foundation Models macOS 27 APIs are optional beta-era accelerators and cannot become a base gate.

## Research adoption rule

Every candidate needs: a Bimax baseline, a falsifiable hypothesis, preserved raw results, a mutant,
a reliability/safety budget, a device/OS matrix where relevant, and an explicit rollback. Paper
numbers are reported results, not expected local gains.
